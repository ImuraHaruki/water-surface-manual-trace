# 水面・地表面 手動トレースソフト

時空間画像上で水面と地表面を手動トレースし、水深、地表面高度変化、フルード数、シールズ数をフレーム単位でCSV出力するWindows向けソフトです。

## 起動

`run_manual_trace.bat` をダブルクリックします。このPCのAnaconda環境を使って起動します。

## 基本操作

1. 「画像を開く」で `*_spacetime_axes_y2.png` などの時空間画像を開きます。
2. 水面または地表面を選びます。
3. 「点をクリックして結ぶ」または「ドラッグで描く」で線を入力します。
4. 後から直す場合は「点・線を修正」を選びます。既存の丸い点、または線上の直したい場所をドラッグしてください。線上をドラッグすると、その位置に修正点が自動追加されます。
5. 線を途中で切る場合は「新しい区間（線を切る）」を押します。区間間は補間されません。
6. 水面が画像上方または下方へ外れた区間は、操作欄で対応する項目を選び、時間方向にドラッグします。間違えた場合は「最後の画像外区間を戻す」を押します。
7. 「名前を付けて保存」で `.trace.json` プロジェクトを保存します。
8. 必要に応じて流速CSVを読み込み、列と単位を確認します。不要になったCSVは「選択を解除」で未選択に戻せます。
9. 粒径、密度、シールズ数の計算方式と係数を設定します。
10. 「結果CSVを書き出す」を押します。

「グラフを表示」を押すと、現在のトレースと設定値から次のグラフを表示します。先にCSVを書き出す必要はありません。

- 元の時系列画像（水面・地表面トレースを重ね、各グラフと時間軸を共通化）
- 水面高度・地表面高度
- 水深・水深下限値
- オプティカルフロー流速
- フルード数・シールズ数
- 地表面高度変化（一番下に独立表示）

グラフ画面の「グラフを画像保存」からPNGまたはPDFで保存できます。また「手動測定値CSVを書き出す」では、各手動測定時刻の流速、フルード数、シールズ数、地表面高度変化量、地表面高度変化率（dη/dt、cm/s）をまとめて保存できます。欠測区間や画像外区間は、前後の線をつながず空白または水深下限値として表示します。
フルード数・シールズ数の縦軸は、1を中央の目盛りとして比較しやすくするため、常に0～2で表示します。範囲を超える値も結果CSVにはそのまま出力されます。
グラフ表示画面では、Fr軸・θ軸それぞれの最小値と最大値を入力し、「軸を反映」で表示範囲を任意に変更できます。
水面が画像上方へ外れた区間では、画像上端を仮の水面とした無次元数の参考値を別途計算し、フルード数・シールズ数グラフに点線で示します。通常値や相図の観測値とは混ぜません。

未保存の変更がある状態でソフトを閉じる、または別の画像・プロジェクトを開くと、「保存」「保存しない」「キャンセル」に相当する確認画面が表示されます。「保存」を選ぶと、その場でプロジェクトを保存してから操作を続けます。

## フルード数・シールズ数相図

画面上部の「Fr–θ相図」を押すと、現在のトレース結果からOhata et al. (2017) Figure 8左列を背景とした3粒径帯の相図を表示します。

- 横軸: `log10(シールズ数 θ)`
- 縦軸: `log10(フルード数 Fr)`
- 細粒砂・中粒砂・粗粒砂の3相図
- 点、時刻順の線、点＋線を選択可能
- 開始時間・終了時間を数値欄またはバーで指定可能
- 指定した時刻範囲で点・線を順に追加するアニメーション表示（バックグラウンドで作成後、別ウインドウで滑らかに再生。動画時間を設定可能）
- 横軸・縦軸の表示範囲を数値欄またはバーで調整可能
- 点と線の色は経過時間
- 表示中の相図をPNGまたはJPEGで保存可能
- 対応・対数化CSV、PNG、設定JSONをまとめて出力可能

Figure 8左列から読み取った固定境界を使用し、Table 2の判別式は相図描画に使用しません。Frまたはθが空欄、0以下、非数の行は相図から除外し、その理由を出力CSVの `plot_status` に記録します。

右ドラッグで表示移動、マウスホイールで拡大縮小できます。「一つ戻す」または `Ctrl+Z` で、直前の点追加、ドラッグ描画、点移動、区間削除、画像外指定などを一操作ずつ戻せます。`Ctrl+S` は保存です。

## 出力値

- 水面・地表面の元画像Y座標
- 下端を0 cmとした水面・地表面高度
- 水深
- 水面が画像上方にある場合の水深下限値
- 基準時刻からの地表面高度変化
- 読み込んだ流速（m/s）
- フルード数
- 河床せん断応力
- シールズ数
- 欠測・画像外などの品質フラグ

## 計算式

- フルード数: `Fr = |U| / sqrt(g h)`
- シールズ数: `theta = tau / ((rho_s - rho) g d50)`

せん断応力 `tau` は次から選択します。

- エネルギー勾配: `tau = rho g h S`
- Darcy摩擦係数: `tau = rho f U^2 / 8`
- Manning式: `tau = rho g n^2 U^2 / h^(1/3)`

シールズ数は設定値によって変わるため、d50、密度、勾配・摩擦係数・粗度係数を必ず確認してください。
新規に画像を開いた場合、シールズ数の計算方式はDarcy摩擦係数方式が初期選択です。

地表面高度変化は基準時刻より上昇した場合を正、低下した場合を負として出力します。水面が画像上方にある区間は水深を確定できないため、画像上端までの深さを「水深下限値」として出力します。

## 流速CSV

列名は自由です。読み込み後に時刻列と流速列を選択します。既存の `flow_velocity_results.csv` では通常 `time_s`、`velocity`、単位 `cm/s` を選択します。

## 手動計測流速

「手動計測流速CSV（点表示）」で、オプティカルフローとは別に手動計測の時刻・流速データを読み込めます。時刻列、流速列、単位を選択してください。通常のグラフでは、流速は赤い点、フルード数はオプティカルフローの緑線に対応する緑系の点、シールズ数は紫線に対応する紫系のひし形点で表示します。その時刻のトレース水深を用いてフルード数・シールズ数も計算します。

Fr–θ相図にも手動計測値を時刻色のひし形点として重ねて表示します。手動計測値どうしは連続的なデータとして扱わず、表示方法を「線」にしても線では結びません。

結果CSVを書き出すと、通常のフレーム単位CSVに加えて、`_manual_velocity.csv` を付けた手動計測点ごとの計算結果CSVも出力されます。
